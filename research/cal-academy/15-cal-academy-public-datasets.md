CASCCG genomics, Microbiology, Anthropology, Diatoms with 0 published records). Access: GBIF REST API (`/v1/occurrence/search?datasetKey=…`), GBIF download (DwC-A / simple CSV / SQL), iDigBio API where ingested.

**Practical notes for the designer**
- Everything in GBIF can be bulk-downloaded as one DwC-A by `publishingOrg=66522820-055c-11d8-b84e-b8a03c50a862` (4.2M rows) or per dataset; image URLs are in the `multimedia` extension.
- iNaturalist API: use `per_page=0` for counts, `/observations/histogram` for time series, `/observations/species_counts`, and the AWS bucket for anything >10k rows.
- Respect the Academy's non-commercial terms on specimen images and Sketchfab's request form; data records themselves are CC0 (CC BY for AntWeb, CC BY-NC for Geology/Egg sets).
- Not found / not public: Living Roof sensor feed, energy dashboard, iCal/JSON events feed, ticketing API, Twilight Zone dive logs, a "Coral Reef Image Bank", a `github.com/calacademy` org, a Microbiology portal, CAS participation in CCGP, Memoirs on BHL.
